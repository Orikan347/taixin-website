# 搜尋收錄與成效量測啟用包

階段：`PENDING_RELEASE_SECURITY`

這個工具包不會登入 Google、Bing、Vocus 或任何分析平台。它把「網站可被讀取」與「真的已被收錄、有成效」清楚拆開，避免把 sitemap 或程式碼存在誤說成已收錄。

## 已可自動驗證

1. 公開 Blog、每篇文章、robots、sitemap、RSS 都能實際 HTTP 讀回。
2. 每篇公開文章有 `index,follow`、self-canonical、`BlogPosting`、可見作者與 Vocus 原始來源。
3. 匯入的 Google Search Console／Bing Webmaster aggregate CSV 只接受官網既有 canonical URL，並拒絕 visitor ID、搜尋字詞、帳密與客戶資料。

## 本次真實公開讀回

2026-07-14 以公開網址唯讀讀回：37 篇文章、Blog 首頁、robots、sitemap 與 RSS 全部 HTTP 200；每篇均確認 `index,follow`、self-canonical、`BlogPosting`、可見作者與 Vocus 原始來源。結果保存於 `public-discovery-readback.json`，狀態為 `PASS`。

同日以唯讀 Vocus API 讀回全部 37 篇公開文章，`canonicalURL` 均為空字串。因此官網的 self-canonical 已公開，但 Vocus → 官網 cross-domain canonical 全站皆為 `PENDING_OWNER_VOCUS_SETTING`，不可宣稱已完成。

## 現在的外部平台狀態與下一步

1. **Google Search Console 已完成擁有權驗證與 sitemap 重新提交。** 2026-07-14 的最新畫面仍顯示 `/sitemap.xml` 為「無法擷取／0 網頁」，所以只能記為 `GOOGLE_SITEMAP_FETCH_FAILED_REQUIRES_FOLLOW_UP`；不能宣稱已收錄。公開 Blog 首頁先前的即時網址測試為可建立索引，且已送出一次要求建立索引。
2. **Bing Webmaster Tools 仍是 `PENDING_EXISTING_OWNER_ACCOUNT`。** 未建立外部帳號、未登入、未提交 sitemap；若已有既有帳號，才可新增同一 property 並送出同一 sitemap。
3. Google 或 Bing 出現第一批頁面層級資料後，匯出或人工彙整「頁面層級、最近 28 天」aggregate 數字到 `search-performance.snapshot.template.csv`；不要填搜尋字詞、訪客資料、帳密或下載原始後台檔。

## 完成定義

- `verify_public_blog_discovery.py` PASS：代表公開頁與 crawler-facing 檔案可讀；**不代表** Google、Bing 已收錄。
- Search Console 與 Bing 都有 property／sitemap 成功讀回，且至少一份 aggregate snapshot 通過驗證：才可說「收錄與搜尋成效量測已啟用」。目前尚未達成。
- CTA 轉換量測仍是 `PENDING_ANALYTICS_PROVIDER_DECISION`：尚未獲得選用分析平台與 tracking ID 的授權，不插入任何第三方追蹤碼。
- `verify_blog_operational_closure.py` 只有在 Vocus canonical、Google／Bing owner 讀回與第一份 aggregate 全部有證據時才會回傳 `RELEASE_READY`；它不會因為本機或公開 HTTP 驗證通過而放寬這些門檻。
