# 搜尋收錄與成效量測啟用包

階段：`FUNCTIONAL_TEST_READY`

這個工具包不會登入 Google、Bing、Vocus 或任何分析平台。它把「網站可被讀取」與「真的已被收錄、有成效」清楚拆開，避免把 sitemap 或程式碼存在誤說成已收錄。

## 已可自動驗證

1. 公開 Blog、每篇文章、robots、sitemap、RSS 都能實際 HTTP 讀回。
2. 每篇公開文章有 `index,follow`、self-canonical、`BlogPosting`、可見作者與 Vocus 原始來源。
3. 匯入的 Google Search Console／Bing Webmaster aggregate CSV 只接受官網既有 canonical URL，並拒絕 visitor ID、搜尋字詞、帳密與客戶資料。

## 本次真實公開讀回

2026-07-14 以公開網址唯讀讀回：37 篇文章、Blog 首頁、robots、sitemap 與 RSS 全部 HTTP 200；每篇均確認 `index,follow`、self-canonical、`BlogPosting`、可見作者與 Vocus 原始來源。結果保存於 `public-discovery-readback.json`，狀態為 `PASS`。

同日以唯讀 Vocus API 讀回〈德性能力結果金字塔〉的 `canonicalURL` 欄位為空字串。因此官網的 self-canonical 已公開，但 Vocus → 官網 cross-domain canonical 仍是 `PENDING_OWNER_VOCUS_SETTING`，不可宣稱已完成。

## 網站擁有者需要做的三件事

1. 在既有 **Google Search Console** 新增或選取 `https://orikan347.github.io/taixin-website/` property，送出 `https://orikan347.github.io/taixin-website/sitemap.xml`。
2. 在既有 **Bing Webmaster Tools** 新增相同 property，送出同一 sitemap。
3. 各自完成讀回後，匯出或人工彙整「頁面層級、最近 28 天」數字到 `search-performance.snapshot.template.csv`；不要填搜尋字詞、訪客資料、帳密或下載原始後台檔。

## 可重跑指令

公開可讀性（唯讀網路）：

```bash
python3 scripts/verify_public_blog_discovery.py \
  --site-root . \
  --base-url https://orikan347.github.io/taixin-website \
  --cache-bust <latest-commit-sha> \
  --report 內部工作資料/2026-07-13_個人網站部落格/public-discovery-readback.json
```

成效快照（純本機、去識別化 aggregate）：

```bash
python3 scripts/verify_blog_search_metrics_snapshot.py \
  --site-root . \
  --snapshot 內部工作資料/2026-07-13_個人網站部落格/search-performance.snapshot.csv \
  --report 內部工作資料/2026-07-13_個人網站部落格/search-performance.report.json
```

## 完成定義

- `verify_public_blog_discovery.py` PASS：代表公開頁與 crawler-facing 檔案可讀；**不代表** Google、Bing 已收錄。
- Search Console 與 Bing 都有 property／sitemap 成功讀回，且至少一份 aggregate snapshot 通過驗證：才可說「收錄與搜尋成效量測已啟用」。
- CTA 轉換量測仍是 `PENDING_ANALYTICS_PROVIDER_DECISION`：尚未獲得選用分析平台與 tracking ID 的授權，不插入任何第三方追蹤碼。
