## 1. 共用資料與兩條判斷線

### 前置表單（只收一次）

`姓名、Email、西元生日、地區、目前角色、產業/產品或服務、目前最想解決的問題、保存同意`。

### A. 銷售天賦線

只使用學生自己對壓力、合作與選擇的回答判斷 DISC；不使用客戶異議或產業替學生貼標籤。

| 節點 | 問題 | 四型訊號 |
|---|---|---|
| `talent-friction` | 事情不順時，最讓你受不了哪一種狀況？ | D：拖延無結論；I：冷掉沒互動；S：被逼與衝突；C：資料混亂無依據 |
| `talent-pressure` | 壓力一來，你通常先怎麼做？ | D：直接推下一步；I：先把互動拉回來；S：先穩住關係；C：先補資料和判斷 |
| `talent-collaboration` | 跟你合作的人，最常感受到你哪一點？ | D：推進；I：帶動；S：安心；C：可靠 |

判斷規則：至少兩個訊號一致才定為主要型；最高兩型相近時公開寫「偏向 X 型」，不可硬判。

### B. 課程推薦線

只使用學生面對的對象、對方當下的狀況與想補強的能力推薦課程。

| 節點 | 問題 | 下游分流 |
|---|---|---|
| `course-audience` | 客戶通常是哪一種人？ | 上班族/家庭、企業老闆/主管、高價專業服務、招募團隊/合作夥伴 |
| `course-situation` | 最近一次對方沒有往前走，最像哪一種情況？ | 依前題只顯示相關的三個情境 |
| `course-skill` | 下次遇到同樣情況，你最想先補強哪一段？ | 名單、需求/成交、信任/看人、表達、追蹤效率、帶人複製 |

五連問路徑：

```text
前置表單的目前問題
→ 學生的自然反應
→ 學生的做事方式
→ 面對的客戶或團隊
→ 對方真實狀況
→ 最該補強的下一步
```

## 2. 主流程

```text
開始探索
→ 立即招呼（姓名 + 說明接下來三題）
→ 天賦線三題
→ 顯示銷售天賦報告
→ 學生可選：課程介紹 / 我的銷售天賦
→ 課程推薦線三題（需要個人路徑時才問）
→ 五堂課總覽
→ 單堂課三個 MBAF 節點
→ 我都清楚了
→ 八種學生疑慮
→ 學習順序、課程頁、報名、LINE
```

所有聊天畫面固定保留：`課程介紹`、`我的銷售天賦`。切換主線時保留表單與歷程，不要求重填。

## 3. 銷售天賦報告

固定輸出：

1. 銷售優點三點：只來自學生 DISC。
2. 銷售天賦三點：只來自正式生涯運數主數、正式連線或缺數資料。
3. 建議補強的點三點內：DISC 盲點加正式缺數功課，白話而可做。
4. 給你的實戰建議：回扣學生選的問題。
5. `Orikan 李泰欣送你一句話`：只用正向、能幫到學生的金句庫。
6. 建議學習順序。

禁止：自行命名生涯運數連線、固定套同一份報告、以「銷售力不從心，因為從沒遇過李泰欣」作為報告贈句。

## 4. 五堂課 MBAF 樹

學生不會看見 MBAF 英文字。每個節點都依序包含：

```text
Mini Yes：接住學生已選的狀況
Benefit：少掉什麼困擾，得到什麼結果
Advantage：泰欣老師和一般做法差在哪裡
Feature：課堂哪個方法/段落協助他
```

| 課程 | 三個固定學生問題 | 4U 對應來源 |
|---|---|---|
| 流量磁鐵 | 客戶從哪裡來／內容為何沒詢問／名單流失怎麼辦 | 銷售顧問 `sales-1` 名單分支 |
| 成交地圖 | 再想想怎麼接／太貴怎麼說價值／不靠臨場怎麼成交 | `sales-1` 成交分支、異議處理 |
| 直指人心 | 如何看懂客戶／D I S C 怎麼說／不信任怎麼辦 | `sales-1` 客戶類型分支 |
| 言之有物 | 產品為何講不進心裡／故事怎麼講／帶人怎麼講經驗 | `sales-3` 表達與帶人分支 |
| 極致效率 | 忙卻沒結果／忘記追蹤／如何複製團隊 | `sales-2` 忙碌分支與團隊 SOP 分支 |

同一節點要依學生 DISC 使用 4U 對應語氣：D 給結果與選擇；I 給畫面和熱度；S 給安心與步驟；C 給結構和依據。內容事實相同，但說法不可相同。

每個課程節點都提供：三個延伸問題 + `我都清楚了`。三個問題必須對應三個不同節點，回覆與下一題不得相同。

## 5. 五堂課後的疑慮樹

開場：

> 五堂課你都看過主重點了。真的要做決定前，如果心裡還卡著一件事，直接點出來就好，我幫你把它講清楚。

按鈕：

1. 我覺得課程還是太貴了
2. 我還想再想一想
3. 我以前上課沒效果，怕這次也一樣
4. 我現在真的抽不出時間
5. 我需要先跟主管或家人討論
6. 我覺得自己看書、看影片就好了
7. 我怕自己學不會，最後還是做不出成果
8. 沒有疑慮了

每個疑慮的回覆順序固定：

```text
理解顧慮
→ 問清楚真正卡點
→ 接回他前面選的情況
→ 用適合課程做 MBAF
→ 取一個最相關的信任證據
→ 提供清楚下一步
```

信任證據單一來源規則：

- 效果疑慮：超過 300 堂課、17 個產業、50 家企業、全額退費保障、零退費紀錄。
- 汽車：中古車全台第一或保時捷第一。
- 保險：一年實收保費破億。
- 藥廠：業務全台第一。
- 房地產：一年 18 件成交。
- 不在同一段堆全部案例。
