## 2026-07-07｜DISC 回覆策略補強

- 使用者詢問如果學生是 DISC 哪一型，AI 是否知道要怎麼回覆才適合。
- 使用者要求確認是否知道各型想聽什麼話，以及是否有把這個判斷做進後台。

規劃調整：

- 新增 DISC 回覆策略表：
  - D 型：重結果、效率、重點、下一步。
  - I 型：重共鳴、被看見、畫面感、正向可能。
  - S 型：重安全感、穩定、小步驟、不被逼。
  - C 型：重邏輯、依據、結構、可驗證資訊。
- 新增 D / I / S / C 分型回覆模板。
- 新增 DISC 追問策略，用行為題區分混合型。
- 新增 DISC 在不同 phase 的用途：
  - discovery
  - profile_spec
  - accuracy_check
  - recommendation
  - objection_handling
- 新增 DISC 對課程推薦說法的影響。
- 新增混合型處理規則，例如 `I 偏 S`。
- 在 LLM JSON 輸出格式中新增 `response_strategy`，讓後端明確告訴前端 / LLM 這一輪應採用的語氣與避免事項。

## 2026-07-08 V3.1 修正：開始探索招呼、短回答記憶與禁用固定備援追問

修正原因：

- 使用者回報按「開始探索」後沒有先熱情打招呼，第一句看起來像在質問客人。
- 對話在短回答如「保時捷」「企業老闆」「成交」時，會重複問同一句，沒有像真人一樣記住前文。
- Gemini 失敗或回覆不完整時，不可顯示固定備援診斷句，更不可冒充已判斷完成。
- 頭像與分享圖人物照片要保留上半身與完整頭部，不可裁頭。
- 9:16 分享圖底部署名需要保留安全距離，避免分享時被裁切。

本次修正：

- `ai-student-qa.html`
  - 按「開始探索」後立即顯示：「某某某，你好！我是泰欣，我先幫你看一下你的銷售狀況...」並直接接第一題。
  - `start()` 不再額外塞入 Gemini 生成的第一句，避免第一題與固定句重複。
  - 輸入框提示改成具體範例：「例如：我賣保時捷，客戶多半是企業老闆。」
  - 首頁人物、聊天頭像與報告頭像改為臉部置中的 cover crop。
  - 分享圖人物同樣使用 face-centered cover，底部署名 y 座標上移到安全區。
- `lib/gemini-student-qa.js`
  - 移除前端可見固定備援追問；Gemini 失敗只回禮貌的等待 / 重試提示。
  - 新增短回答欄位擷取：商品 / 服務、客戶、問題、目標會從對話中累積，不因回答很短就忘記。
  - 報告 gate 改為至少 3 則有效回答，並且要有 product、customer、problem、goal。
  - 禁止重複問已取得的商品 / 客戶問題。
  - 清掉前端可見的 `<b>` 標籤與固定 AI 感句型。
- `data/gemini-config.json`
  - 移除第二備援 model 設定，避免前端流程依賴 fallback 語意。
